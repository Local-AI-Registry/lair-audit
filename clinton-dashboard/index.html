How these numbers are worked out
  • GitHub activity is every push by htmlHxcker to the LAIR web repo since July 1. His GitHub profile shows almost all of his commits in this repo, plus a few dozen contributions a month in private repos outside LAIR that cannot be seen. Pushes to bay/... branches are agents. Merges, syncs and releases are pipeline and counted for neither side. Everything else is Clinton.
  • Coding hours: 30-minute windows containing a commit he authored (by its own timestamp, so work pushed later still counts) or a push he made, gaps of one hour or less filled. Slack-only hours: the extra windows added when his Slack messages are included. Both count visible work only, so they can undercount, but neither counts agents' time as his. His own pushes may still be written with Claude's help in his own session.
  • Agent hours: the same method applied to bay pushes. Agents can run many bays at once, so this is time running, not work volume.
  • Slack exists only from Aug 3, so July hours are from GitHub alone and read low.
  • Forecast: the average of the last four full weeks blended with the trend since Aug 3, for coding hours and for coding plus Slack. The range is one standard deviation of the last eight weeks.
  • Promise dates: each dated commitment in Slack, matched to the GitHub release or live page that delivered it. "No evidence" means nothing matching was found, not that it never happened.
